# 🏎️ Car Speed Run (Beta)

![Screenshot do Car Speed Run](https://img.itch.zone/aW1nLzMxNzg1OTY0LnBuZw==/105x83%23/%2BPyD4M.png)

Um jogo de corrida infinita 2D desenvolvido em Python. Viaje por diferentes estações do ano, desvie de obstáculos, pule e sobreviva o máximo que puder.

## 🎮 Jogar Agora (Download)

Você pode baixar o executável (.exe) e jogar diretamente no Windows através do Itch.io:
👉 **[Clique aqui para baixar o jogo no Itch.io](https://prof-marcos-barreto.itch.io/car-speed-run)**

## 🕹️ Controles

*   **Setas:** Movimentar o carro.
*   **Enter:** Selecionar / Entrar na fase.
*   **Space:** Pular.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Python 3
*   **Engine:** Pygame
*   **Empacotamento:** PyInstaller
